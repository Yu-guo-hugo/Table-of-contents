Telegraph Station

Hugo Yu's website Selection

1.Chinese version

This is my first website. It only uses keystroke duration detection and
generates periods (.) and hyphens (-) as text.

2.English version

I translated it into English; it can translate Morse code and create rooms.
Most importantly, this version allows online chat.

3.Chats

I've improved the previous version, removing the Telegram feature and
allowing direct text chat. I've also added a password function after room
creation, so no one will find someone already logged in after entering the
room number.

4.Chess

This is a chess webpage that includes the complete rules and instructions
on how the pieces move. It is the most difficult and time-consuming
program I have ever created, and I feel a great sense of accomplishment
upon completing it.
